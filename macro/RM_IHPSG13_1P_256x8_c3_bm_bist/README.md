# RM_IHPSG13_1P_256x8_c3_bm_bist

IHP SG13G2 foundry-provided 256 x 8 single-port SRAM macro with BIST: the chip's DMEM (`DMEM_IMPL` = 1).

## Source

- **Repository**: https://github.com/IHP-GmbH/IHP-Open-PDK
- **PDK revision**: `c4b8b4e5e7a05f375cca3815d51b3a37721fbf5c` (the one the ttihp26b flow installs)
- **Path**: `ihp-sg13g2/libs.ref/sg13g2_sram/`
- These files match the ones Tiny Tapeout's SRAM test project (urish/ttihp-sram-test) uses for its 1024 x 8 macro: the LEF, GDS and CDL of that macro are byte for byte the same in this revision.
