Protocol Emulator Architecture

A small programmable I/O processor: two hardware contexts share one decoder and datapath and drive eight protocol pins under firmware control, so UART, I²C and SPI are programs, not hardwired blocks. Every width below is for the default parameters; all of them are module parameters in the RTL.

From the gate netlists Yosys produced for the model-vs-RTL proofs. Generic synthesis: 6,912 cells; the instruction memory and its read mux dominate.

pe_host_if

Turns the asynchronous 4-bit host bus into single-cycle register accesses. Two nibbles make one address or data byte; the strobe is a toggle that passes a 2-FF synchroniser, and every accepted strobe edge toggles h_ack.

pe_regs

Address decode for the 8-bit register space. Holds every host-visible configuration register, stages 24-bit IMEM words (commit on the last byte, auto-increment, refused while any context runs), and fans the FIFO strobes and error-clear pulses out.

pe_imem

Instruction memory: 64 words × 24 bits = 1,536 bits, one host write port and one registered read port (data one cycle after the address). IMPL=0 uses flip-flops; IMPL=1 latches.

pe_fifo ×2

Synchronous first-word-fall-through FIFO, used as TX (host → firmware pull) and RX (firmware push → host). A write to a full FIFO is dropped and sets the sticky overrun flag unless a read happens in the same cycle.

pe_pins + pe_sync

The pin fabric. Each of the 8 pins has an output and an output-enable register that hold until written, a static owner (which context may write it) and an open-drain mode. Inputs pass a 2-FF synchroniser.

pe_core

Slot scheduler and shared datapath. Slot s belongs to context s; each cycle the core fetches for the next slot's context and executes the current one. One instruction therefore takes NUM_SLOTS = 2 cycles plus any stall.

pe_ctx ×2

Architectural state of one context. The stall counter counts down every cycle, independent of slots; restart loads START_PC and sets stall = 1 to cover the word already fetched from the old PC; a finished vote shifts its bit into ISR and C.

pe_decode

Pure combinational decode of the 24-bit word into 14 one-hot op flags and fields. Opcodes 14–31 are reserved and execute as nop with op_illegal = 1.

pe_exec

The shared combinational datapath (~16k gates in AND/NOT form). Computes the slot context's next state and its side-effect requests. Held instructions (wait not met, blocking pull on empty, blocking push on full) keep PC and change nothing, except a timed-out wait's counter.

pe_vote ×2

Oversample-and-vote unit. After start it samples the selected synchronised pin every S cycles, N samples, counts only the centre N−2k, and returns the majority in bit_out N·S + 1 cycles later. busy covers the done cycle, so the context cannot issue while the bit is written back.
